Databricks AI services

Choose the smallest managed capability that meets the product requirement, then benchmark it against an external retrieval or model stack. AI Search is not “just an embedding model”: retrieval quality is a system property spanning parsing, chunking, metadata, embeddings, filters, freshness, reranking, latency, governance and cost.

The five questionsMosaic AI / Genie / Agent Bricks
The architecture choice is usually between a managed Databricks path and a more flexible external stack—not between “vector search” products in isolation.

Correct mental modelUse Genie for governed structured questions, AI Search/Knowledge Assistant for unstructured evidence, and an Agent Bricks/custom agent only when orchestration or tools are the product—not as a default wrapper around every prompt.
Decision matrix
RequirementStart hereEscalate when…
“Show revenue by segment with governed metrics”Genie AgentQueries require complex multi-step business logic or non-SQL tools.
“Answer from PDFs with page citations”Knowledge Assistant or AI Search + custom RAG appTables/layout/images require custom parsing or benchmark shows poor recall.
“Blend structured facts and documents”Supervisor/Agent Bricks or custom tool-calling agentYou need deterministic routing, custom reranking, multi-provider models, or portability.
“Low-latency online prediction”Model Serving endpointNeed a non-Databricks inference plane, special GPU/runtime, or edge deployment.
Benchmark before arguingBuild a client-specific golden set with expected evidence and answers. Measure retrieval recall@k, nDCG/MRR, citation precision, answer faithfulness, filter correctness, freshness lag, p50/p95 latency, throughput, failure rate, and cost per successful answer.
GUI build path
  1. Register documents in UC Volumes or Delta tables; add stable source IDs, ACL metadata, document version and page/section coordinates.
  2. For AI Search, create an index from the source table, select embedding/sync settings, choose endpoint capacity, and test queries in the UI.
  3. For Knowledge Assistant, create the assistant, select knowledge sources, inspect extracted chunks/citations, add instructions, evaluate, then deploy.
  4. For Genie, create/select a Genie Agent, attach curated tables/metrics, define instructions and sample questions, then test generated SQL and permissions.
  5. For Agent Bricks, compose retrieval/structured/function sub-agents, define routing descriptions, test traces and deploy a serving endpoint.
  6. Connect the deployed artifact to a Databricks App as a declared resource; do not embed endpoint IDs or tokens in source.

w = WorkspaceClient()
result = w.serving_endpoints.query(
    name="my-agent-endpoint",
    dataframe_records=[{"messages":[
      {"role":"user","content":"Summarize the evidence with citations."}
    ]}])

# AI Search / Vector Search SDK shape (index name is environment config)
from databricks.vector_search.client import VectorSearchClient
vs = VectorSearchClient()
index = vs.get_index(index_name="prod.catalog.schema.document_index")
rows = index.similarity_search(
    query_text="defensive efficiency in the 1990s",
    columns=["chunk_id","text","source_uri","page"],
    num_results=8,
    filters={"tenant_id":"demo"})

AI Search vs external retrieval
DimensionDatabricks AI SearchElasticsearch/OpenSearch/Qdrant/Weaviate/pgvector
Retrieval qualityStrong managed baseline; outcome depends on parser, chunking, embedding and filters.Potentially higher with custom hybrid/rerank pipeline, but you own integration and tuning.
Embedding choiceManaged options and supported model endpoints; verify model/region availability.Maximum freedom: HF, vendor APIs, domain-specific models.
Filter performanceUC-aware and integrated with source metadata; benchmark high-cardinality tenant/ACL filters.Often deeper index-level control; must recreate governance semantics.
FreshnessManaged sync; measure lag and update semantics for your source.Direct control over refresh/ingest, at operational cost.
Governance/lineageUnity Catalog permissions, lineage and audit are the differentiator.Requires custom identity, lineage and policy integration.
PortabilityFastest inside Databricks; lock-in to UC/index APIs and platform semantics.More portable, but cloud/ops burden moves to you.
Total costManaged engineering and governance; pay for endpoints/storage/queries.Infrastructure + on-call + integration + egress + security engineering.
Do not skipChunking and metadata design usually dominate embedding-model debates. A beautiful embedding over wrong page boundaries, missing ACL keys, or stale documents still produces a bad product.
